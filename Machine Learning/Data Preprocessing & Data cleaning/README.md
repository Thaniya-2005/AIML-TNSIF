## Overview

This project focuses on cleaning and preprocessing raw datasets before using them for data analysis or machine learning.

The dataset intentionally contains missing values, inconsistent categorical values, invalid values, and other common data quality issues.

## Topics Covered

- Loading CSV datasets
- Exploring datasets using head(), tail(), info(), and describe()
- Identifying missing values
- Filling numerical missing values using mean
- Filling categorical missing values using mode
- Removing duplicate records
- Converting data types
- Converting date columns to datetime
- Standardizing inconsistent text
- Renaming columns
- Filtering invalid values
- Selecting multiple columns
- Applying transformations
- Creating new columns
- One-Hot Encoding
- Sorting datasets
- Saving cleaned datasets

## Dataset Columns

The practice dataset contains:

- Name
- Age
- Gender
- Marks
- Attendance
- City
- Date

## Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

## Objective

The objective is to transform messy raw data into clean and structured data suitable for further analysis and machine learning.

## Learning Outcome

This project helped me understand the importance of data quality and how Pandas and NumPy can be used to prepare datasets for machine learning.
