## Overview

This project contains implementations of different supervised machine learning algorithms using Python and Scikit-learn.

## Algorithms Covered

- Logistic Regression
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest
- Polynomial Regression
- Naive Bayes

## Tasks Performed

- Created sample datasets
- Selected input and target variables
- Trained machine learning models
- Generated predictions
- Evaluated classification performance
- Visualized model results
- Implemented Spam Email Detection

## Spam Email Detection

A simple text classification model was created to classify emails as:

- Spam
- Not Spam

The project uses:

- CountVectorizer for converting text into numerical features
- Multinomial Naive Bayes for classification

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Learning Outcome

This project helped me understand the basic workflow of supervised machine learning, including data preparation, model training, prediction, classification, regression, and model visualization.
