# Netflix Data Visualization Project

This project explores and visualizes the Netflix dataset using Python. It focuses on understanding the distribution of movies and TV shows and identifying major content contributors.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Loaded and explored the Netflix dataset
- Handled missing values
- Visualized Movies vs TV Shows
- Identified the Top 15 content-producing countries
- Identified the Top 15 directors
- Used pie charts and bar plots for visualization

## Objective
To practice data analysis and visualization techniques using a real-world Netflix dataset and extract meaningful insights from the data.
