## Overview

This project analyses the marks of 10 students and represents their performance graphically.

## Tasks Performed

- Created a student marks dataset
- Displayed marks using bar charts
- Identified the highest scorer
- Added chart titles and axis labels
- Sorted marks in descending order
- Visualized the sorted marks
- Explored patient age distribution as an additional challenge

## Technologies Used

- Python
- Pandas
- Matplotlib
- NumPy

## Learning Outcome

This project helped me understand basic data analysis, sorting, statistical analysis, and data visualization using Python.
